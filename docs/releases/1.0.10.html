Fire 1.0.10 “Ignition”

Fire is a local, agent-first control plane for the space around your Mac's menu bar. This is the recommended Fire 1.0 release.

  • Context Scenes let coding agents propose approved behavior for the app, time, or battery context you are in.
  • Fireline shows one useful thing below the notch or menu bar, such as a local AI quota or a selected menu bar item.
  • Fire CLI and agent skill provide guided setup, diagnostics, exact selectors, and recovery.

Fire 1.0.10 reliability

  • Expected authorization modals are excluded from App Hang telemetry at capture time, without hiding genuine hangs elsewhere in Fire.
  • Consent prompts expire fail-closed inside AppKit's modal-panel run loop before their MCP client deadline, so unanswered prompts cannot occupy the Context Scene relay.
  • Agent-facing XPC requests hand off async replies so Context Scene reads and approvals do not deadlock their main-app relay.
  • Fresh sessions use a private, mutually authenticated local socket through the running Fire app.
  • Blocking socket semantics and bounded helper timeouts prevent hangs and recover on the next call.

Your existing preferences, permissions, saved layouts, update path, and approvals are preserved. For compatibility, macOS System Settings may still list Fire as Ice.
