Fire 1.0.6 “Ignition”

Fire is a local, agent-first control plane for the space around your Mac's menu bar. This is the recommended Fire 1.0 release.

  • Context Scenes let Codex, Claude Code, or OpenCode propose approved behavior for the app, time, or battery context you are in.
  • Fireline shows one useful thing below the notch or menu bar, such as local AI quota status or a selected menu bar item.
  • Exact item selectors prevent the wrong status item from being moved when one app owns several.
  • Fire CLI and agent skill provide guided setup, diagnostics, and recovery.

Fire 1.0.6 reliability

  • Fresh CLI and agent sessions connect through the running Fire app, so reads, Context Scenes, and approved changes share its backend and consent relay.
  • The server restores blocking semantics on accepted local sockets, preventing an EAGAIN race from closing fresh CLI sessions.
  • Socket frames use explicit mutable buffers, and requests above a fixed 1 MiB bound are rejected.
  • The private local transport authenticates both executables with their audit tokens, code signatures, exact paths, Developer ID team, and current macOS user.
  • Context and write requests fail immediately with a clear setup message when Accessibility or Fire's menu-bar setup is not ready.
  • Bounded helper and request timeouts prevent a stopped service from hanging the agent bridge indefinitely.

Your existing preferences, permissions, saved layouts, update path, and approvals are preserved. For compatibility, macOS System Settings may still list Fire as Ice.
