Fire 1.0.21 “Ignition”

Fire is a local, agent-first control plane for the space around your Mac's menu bar. This is the recommended Fire 1.0 release.

  • Context Scenes let coding agents propose approved behavior for the app, time, or battery context you are in.
  • Fireline shows one useful thing below the notch or menu bar, such as a local AI quota or a selected menu bar item.
  • Fire CLI and one shared agent skill provide guided setup, diagnostics, exact selectors, and recovery for Codex, Claude Code, and OpenCode.

Fire 1.0.21 recovery

  • Repair and Retry now restores Fire's hidden-section divider even when macOS has removed it from the menu bar entirely.
  • The repair preserves Fire's saved divider position, permissions, and the arrangement of other applications' menu bar items.
  • Built-in Fire icons explicitly use template rendering and a semantic foreground color, keeping the Fire control visible on dark and light menu bars.
  • Surfaces shows explicit loading, ready, and recovery states instead of an endless spinner when divider discovery fails.
  • Settings and Permissions open at their full intended size on macOS 26, including normal reopens from Finder or the command line.
  • Menu-bar image capture and color averaging run away from the main thread and coalesce overlapping refreshes, removing a Sentry-confirmed App Hang while Settings or search is visible.
  • The Permissions screen refreshes macOS privacy grants immediately when it appears or Fire becomes active.
  • The canonical agent skill maps “surface Fantastical while I use Mail” directly to a selected-item Fireline, without moving the normal menu bar item unless requested.
  • OpenCode setup copies a valid local MCP JSON block instead of prose.

Reliability

  • Expected authorization modals are excluded from App Hang telemetry at capture time, without hiding genuine hangs elsewhere in Fire.
  • Consent prompts expire fail-closed inside AppKit's modal-panel run loop before their MCP client deadline.
  • Agent-facing XPC requests hand off async replies so Context Scene reads and approvals do not deadlock their main-app relay.
  • Fresh sessions use a private, mutually authenticated local socket through the running Fire app.

Your existing preferences, permissions, saved layouts, update path, and approvals are preserved. For compatibility, macOS System Settings may still list Fire as Ice.
